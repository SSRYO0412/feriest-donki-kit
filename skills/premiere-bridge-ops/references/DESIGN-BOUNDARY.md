# 設計の境界線 — 何をテンプレに持たせ、何を諦めるか

**作る前にここを読む。** 「やってみたけど無理だった」を繰り返さないための地図。
すべて実機で確認済み（2026-08-08〜09）。

---

## 1. 判断基準はひとつ

> **クリップ全体に掛かるものか、文字の中に踏み込むものか。**

- **全体に掛かるもの** → **Premiere側で後からいくらでも足せる。AE不要**
- **文字の中に踏み込むもの** → **AEでテンプレに仕込むしかない**

| やりたいこと | AEなしでいけるか |
|---|---|
| 位置・サイズ・回転・不透明度 | **✅ Premiere側で自由**。キーフレームも打てる |
| エフェクト（**136種**）とそのキーフレーム | **✅ 自由**。MOGRTクリップにも効く（実測で値が一致） |
| 白フラッシュ・弾性バウンド・ジッター等の演出 | **✅**（`UI-EQUIV.md` に実測レシピ） |
| **文字単位の強調・1文字ずつ出す・文字ごとの色** | **❌ AEで仕込む** |
| **書体・フチ・文字の中身** | **❌ AEで仕込む**（ただし書体は§3） |
| マスクを使う表現 | **❌ スクリプト不可**（UIなら可）。別トラックに重ねて回避 |

## 2. ★原理的に無理なもの（やる前に諦める根拠）

| できないこと | 理由 | 回避策 |
|---|---|---|
| **文字単位のグロー** | グローはレイヤーに掛かるエフェクトで、描画結果全体に効く。アニメーターに光り物のプロパティが無い | **行を分けて別クリップにする**（§4）。または2レイヤーの相補マスク |
| **マーカー・下線の帯** | 「何文字目から何文字目」の**部分範囲の幅を取る手段が無い** | 行全体に敷くなら可 |
| **ラン単位の色** | per-run の配列に色が無い | アニメーター＋範囲セレクターで作る |
| **露出項目の後付け** | MOGRTの構造は静的 | 設計時に余裕を持たせる。増やすなら作り直し＋配置済みクリップの差し替え |
| **レイヤーの動的追加** | 同上 | スロット数Nは決め打ち（実務は3で足りる） |
| ~~色をスクリプトから設定~~ | **解決済み**。カラー型は `setValue` が2^32-1で頭打ちになり赤に手が届かないが、**0〜100の数値スライダー3本**で持たせれば完全に指定できる | `assets/telop_3slot_v22.mogrt` |
| **エフェクトの適用順の変更** | `moveComponent` 等が存在しない | **付ける順番を最初から正しくする** |
| **マスク・調整レイヤー・プリセット** | API自体が無い | 別トラックに重ねる／レシピJSONで代替 |
| **レイヤースタイル**（境界線・光彩） | `canSetEnabled=false`。メニュー経由でも付かない | テキストアニメーターで作る |
| **AEのEGP「範囲を編集」** | スクリプトから設定する手段が見つかっていない | **既定レンジ0-100に収まるよう設計する** |

## 3. 書体は焼き込まない

「書体ごとにレイヤーを焼き込んでドロップダウンで出し分ける」設計は、
**「Premiereからフォントを変えられない」という前提で組んだもので、その前提は覆った。**

| | 焼き込み | **フォント編集を解禁** |
|---|---|---|
| 使える書体 | テンプレに入れた数だけ | **インストール済みなら何でも** |
| レイヤー数 | 書体の数だけ | **1枚** |
| 式の数 | 書体数に比例（5書体で75件） | 増えない（**31件**） |
| 書体を足したいとき | **作り直し＋配置済みクリップの差し替え** | 不要 |
| 人がUIで選ぶ | ドロップダウンで選べる | フォント名を打つ／スクリプトで指定 |

**スクリプトから制御するなら後者が明確に有利。** 焼き込みは「人がUIで選ぶ」運用に限って意味がある。
解禁は `scripts/mogrt_enable_font_edit.py`（`.mogrt` の `definition.json` を書き換える）。

## 4. 文字単位でできないことは「行を分割」して解決する

**「これは」「グローです」を別々のMOGRTクリップとして横に並べる。**
後者だけ光らせられるし、**書体・サイズ・出現タイミングもクリップごとに独立**する。
**テンプレートの変更は要らない。**

- 位置合わせは **AEを文字幅の計算機として使う**（`templates/ae_measure_text.jsx`）
- **単純に幅を足さない**。両端合わせにする（`TELOP-WORKFLOW.md` §3-6）
- 実証: **SSIM 0.999722**（20pxずらした対照 0.987369）

**縦に積む（行単位で分ける）なら幅計算すら要らない。** 2行テロップはこれが自然。

## 5. テンプレの項目を設計するときの原則

1. **後から増やせない。** 迷ったら**入れておく**（式が増えるだけでレイヤーは増えない）
2. **ドロップダウンには必ず「なし」を入れる。** 参考が静止なら動きを足さない、が選べるように
3. **スライダーは既定レンジ 0-100 に収まるよう設計する。**
   例: サイズは基準フォントサイズを大きめ（200px）に焼いて、スライダーは％で持たせる
4. **数値は「追加分」で持たせる。** アニメーターは加算なので、**0なら本文と同じ**になる
5. **効き具合（`g`）は1本の式で作り、複数プロパティで共有する。**
   跳ねたときに大きさ・縁・縦オフセットが**揃って動く**
6. **スロット数Nは決め打ち。** 実務のテロップは1行に3箇所も強調しないので**3で足りる**
7. **書体は汎用化を狙わない。** 案件ごとに焼き直す方が軽い（生成は数分）
8. **すべての数値を 0〜100 に収める。** EGPのスライダーは**Premiere側で0〜100に丸められる**。
   色は0〜100（％）、サイズは基準を大きく焼いて％で持つ、といった設計にする
9. **色はカラー型で持たない。** スクリプトから設定できない。**数値スライダー3本**にする

## 6. 迷ったときの早見表

| 相談 | 答え |
|---|---|
| もっと派手に動かしたい | **AE不要。** Premiere側のレシピを増やす |
| エフェクトを重ねたい | **AE不要。** ただし**順序は変えられない**ので付ける順を正しく |
| 文字ごとに違う出方をさせたい | **AEでテンプレに仕込む** |
| 特定の語だけ光らせたい | **行を分割して別クリップに** |
| 「この単語を強調」で指定したい | **テンプレ変更不要。** 呼ぶ側で `indexOf` して文字番号に直す |
| 書体を増やしたい | **テンプレ変更不要**（フォント編集を解禁してあれば） |
| 強調を4箇所にしたい | **作り直し**（スロット数は静的） |
