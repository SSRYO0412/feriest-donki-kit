# UI操作 ↔ スクリプトの対応表

「UIでできることをスクリプトでやろうとして詰まる」のを防ぐための一覧。
すべて Premiere **26.3.2** で `typeof` と実操作で確認（2026-08-08）。

## 現行UIのパネル構成（25.0 で変わった）

**Premiere Pro 25.0 以降、旧「エッセンシャルグラフィックス」パネルの機能が
「プロパティ」パネルへ移動した。** 古い解説の「エッセンシャルグラフィックスを開く」は
現行では「**プロパティを開く**」と読み替える。**エフェクトコントロールは廃止されていない。**

| パネル | 役割 |
|---|---|
| **プロパティ** | よく使う操作を素早く。位置/スケール/回転/不透明度/クロップ/速度/音量/テキスト。**複数クリップの一括変更に強い**（値が違う項目は `—` 表示） |
| **エフェクトコントロール**（`Shift+5`） | 適用済みエフェクトの**全設定・順序・マスク・キーフレーム・速度グラフ**。アニメーションの中心 |
| **エフェクト** | エフェクトとプリセットを探して適用 |

プロパティに項目が無くても機能が消えたわけではない。**まず `Shift+5` を見る。**

## 対応表

| UIでやりたいこと | UIの手段 | スクリプト | 実測 |
|---|---|---|---|
| 位置・サイズ・回転・不透明度 | プロパティ | **✅** | モーション/不透明度は固定エフェクト。読み書き・キーフレームとも可 |
| **複数クリップ一括変更** | プロパティ（`—`表示から一括） | **✅** | **ループで回すだけ** |
| エフェクトを適用 | エフェクトパネルからドラッグ | **✅** | `getVideoEffectByName` → `addVideoEffect`（**要アクティブ化**・QE依存） |
| エフェクトの詳細・キーフレーム | エフェクトコントロール | **✅** | 全パラメータ読み書き＋`setTimeVarying`/`addKey`/`setValueAtKey` |
| **属性をペースト**（`Opt+Cmd+V`） | 編集 > 属性をペースト | **✅** | 自前実装で同等（下記） |
| **エフェクトの順序** | エフェクトコントロールでドラッグ | **❌** | `moveComponent`/`reorder`/`setIndex`/`moveTo` **すべて undefined** |
| **プリセット** | 保存 / 適用 | **❌** | `getVideoEffectPresetList`/`applyPreset`/`savePreset` **すべて undefined** |
| **調整レイヤー** | ファイル > 新規 > 調整レイヤー | **❌** | `createNewAdjustmentLayer` 系すべて undefined。QEにも `newAdjustmentLayer` は無い |
| **マスク** | エフェクトコントロールで描画＋トラッキング | **❌** | `addMask`/`createMask`/`masks` **すべて undefined** |

## できない4つと回避策

### ❌ エフェクトの順序変更

**追加した順に後ろへ積まれるだけ。** 実測の並び:

```
0:不透明度 / 1:モーション / 2:グラフィックパラメーター / 3:グリント / 4:アルファグロー
```

順序が絵に影響する組み合わせ（グロー→ブラー と ブラー→グロー は結果が違う）では、
**付ける順番を最初から正しくする**しかない。間違えたら消して付け直し。

### ❌ プリセット

保存も適用もできない。
→ **「レシピJSON ＋ 適用スクリプト」を自前で持つ**のが答え。実質これがプリセットの役割を果たす。
むしろ**バージョン管理できる分こちらの方が扱いやすい**。

### ❌ 調整レイヤー

作れない。ただし **QE に `newTransparentVideo` / `newBlackVideo` / `newColorMatte` はある**。
調整レイヤーの実体は「下のトラックに作用する透明クリップ」なので、
**透明ビデオを上のトラックに置いてエフェクトを付ければ代替できる可能性がある**（**未検証**）。

### ❌ マスク（最も痛い）

UIでは主力（顔モザイク・部分ぼかし・部分カラコレ）で、2026系ではトラッキングも
強化されている（位置/スケール/回転/遠近法/前方・後方・双方向、未割り当てマスク）が、
**スクリプトからは一切触れない**。

**回避策は「マスクを使わない設計にする」。** 実案件の納品プロジェクトを解析したところ、
**マスク0件・調整レイヤー0件・トラックマット0件・描画モード変更0件**で作られていた。
部分的な処理が要るなら、**別トラックに素材を重ねる**方式にする。

## ★エフェクトの複製（「属性をペースト」のスクリプト版）

読んで書けば同等のことができる。**プロジェクトを跨いでも動く**（参考プロジェクトから
作業プロジェクトへ演出を移植できる）。

**読む**:

```javascript
var OFF = clip.inPoint.seconds;              // ★キーフレーム時刻は inPoint 基準
for (var q = 0; q < clip.components.numItems; q++) {
    var comp = clip.components[q];
    // 不透明度/モーション/ベクトルモーション/グラフィックパラメーター/テキスト は組み込み
    for (var r = 0; r < comp.properties.numItems; r++) {
        var p = comp.properties[r];
        if (p.isTimeVarying()) {
            var ks = p.getKeys();            // ★null/undefined を返すことがある
            for (var z = 0; z < ks.length; z++) {
                record(ks[z].seconds - OFF, p.getValueAtKey(ks[z]));   // ★相対時刻で記録
            }
        } else {
            record(p.getValue());
        }
    }
}
```

**書く**: `getVideoEffectByName` → `addVideoEffect` → `setValue` /
`setTimeVarying(true)` → `addKey(OFF + t)` → `setValueAtKey(OFF + t, v, true)`

**実測**: エフェクト2個・パラメータ37件を複製して**34件が完全一致**。
**キーフレームも再現できた**。

**唯一の不一致は色**。色は `18374966858408292000` のような**パック整数**で返り、
同じ値を `setValue` しても `4294967295`（`0xFFFFFFFF`＝白・既定値）のままになる。

★**原因が判明した（2026-08-09）。読む表現と書く表現が違う。**
`getValue()` は 64bit の `[A:16][R:16][G:16][B:16]`（各チャンネルは `値<<8`）を返すのに、
`setValue()` は **32bit に丸める**ので、64bit の値を渡すと `0xFFFFFFFF` に潰れる。
配列を渡すと `Illegal Parameter type`。**色はスクリプトから確実には設定できない。**
詳細と実測値は `MOGRT.md` §6-2。**数値パラメータは問題なく往復する。**

### 「属性をペースト」の挙動（公式仕様・スクリプトでも同じ性質）

- **固定エフェクト**（モーション/不透明度/タイムリマップ/音量）は**コピー先の値を上書き**
- **通常エフェクト**は既存を残して**末尾に追加**
- コピー先のクリップが短いと**キーフレームがアウト点の外側に出る**

## 実測した演出レシピ（参考動画の解析から）

クリップの種類（実写・PNG・ネイティブGraphic・MOGRT）に関係なく同じ手が使える。
**中身が何で作られているかはエフェクトの適用に影響しない。**

| 演出 | 実装 | 実測値 |
|---|---|---|
| **白フラッシュ** | `プロセスアンプ` の**明度**にキーフレーム | `0.000s=100 → 0.100s=80 → 0.200s=35 → 0.333s=0`（10F）。**等速でなく後半で急に落ちる** |
| **弾性バウンド** | **モーション スケール**に16キー | `35.5→61.5→96.5→114→121→111→101.5→91.5→93→96.5→100.5→104.5→104→103→101.5→100.5`（0.5秒＝15F・3回振動して収束） |
| **ジッター** | **モーション 位置**に17キー | ±0.002程度の微振動（正規化座標） |
| **小ポップ** | モーション スケール3キー | `96.6→104.2→100` |
| **キラン（光が走る）** | **エフェクトではなく動画素材**を別トラックに0.46秒重ねる | マスクが使えないためエフェクトでは作れない |

★`プロセスアンプ` の明度は**既定値 0**。`100` まで上げると全体が白く飛び、
アルファは効いたままなので**文字の形を保って白く光る**。

★これらは **MOGRT クリップにもそのまま移植できる**（実証済み）。
参考プロジェクトから読んで MOGRT へ流し込み、値が完全一致した。
