## 設計原則（v2で確定したもの）

1. **正本はJSON/py。** Premiereのシーケンスは常に「正本から生成された出力」。
   タイムラインの手編集は原則行わない。行った場合は**申告制**とし、
   申告の有無にかかわらず**タイムラインdiff（[8]）が正本との食い違いを機械検出**する。
2. **視聴の入れ子。** 検査ゲートの列に頼らず、各段階で安い成果物を実際に**見る**。
   静止で守る「内容」（[3.5]採点ループ＝Codex敵対採点で95点まで）と、
   動きで守る「知覚」（[6]G19通し視聴）の二段。機械ゲートは視聴の裏付け役。
3. **DAGによる自動再実行。** cutlist→telops→broll→se→配置の依存を1本のランナーが管理し、
   上流が変わったら下流の再生成と検品が**自動で**走る。「回し忘れ」を構造的に不可能にする
   （qc_inserts.py の回し忘れで先出しを見逃した事故の再発防止）。
4. **高価な手戻りは組む前に消化する。** 組み直し級の欠陥（カット選定ミス・素材の当て違い・
   裏側の会話の混入）は**[3.5]採点ループ**で、微調整級だけが[6]以降に残る構造にする。
5. **検出器・ゲートは陽性の検証用データで当たることを確かめてから使う。**
   実データ0件は「問題が無い」と「検出器が壊れている」を区別できない。
6. **正本のver管理。** ファイルは上書き禁止・連番新版（従来どおり）＋ work/ をgit管理し、
   「どの正本の組がどのレンダーを生んだか」をコミットで固定する。

### [0-1] 受入れ・実測

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 <素材>
ffprobe -v error -select_streams v:0 -show_entries stream_side_data=rotation -of default=nw=1 <素材>
```
- 実尺を必ず自分で測る（フレーム抽出の枚数から推定しない）
- **`rotation` を必ず見る。** `-90`付きだと ffprobe は回転前を返すのに ffmpeg は回転後で出力。
  寸法が要る処理は**1フレーム書き出して実寸を読む**（映り込み検出器が沈黙のまま壊れた実績）
- 素材の総量（本数×秒）を先に出す。後の設計はこの上限に縛られる
- 件数検証（DL=動画数・メタ=ユニークrel）。日本語パスはNFC/NFD差に注意（exFATはNFD）

## [1] 音声正本 — 元音声の語と無音

1. 音声抽出（`-ac 1 -ar 16000`）→ faster-whisper 語タイムスタンプ付き → `words.json`
2. 音量包絡 → `env.npy`

**無音の判定（切り位置の唯一の根拠）**
```python
db = 20*log10(max(env, 1e-6))   # ★線形振幅→dB。忘れると条件が常に真
db = 20msの移動中央値で平滑      # ★平滑しないとクリック1点で無音が分断される
無音 = db < -42dB が 0.18秒以上
```
- whisperの語タイムスタンプは切り位置の根拠にしない（検証にだけ使う）
- 切ってよいのは無音の中だけ。out=語末+0.05秒 / in=語頭−0.05秒
- 将来: Qwen3-ASR（日本語CER・固有名詞F1でwhisper超）＋kotoba-whisper の多重化投票

## [2] 構成設計 — 台本レベルの編集判断

> ★2026-07-30更新: カット選定の正本は skill `short-video-cut-craft`。参考動画の1秒分析シートが
> ある案件は `references/REF-DRIVEN-SELECTION.md`（3軸評価・S0〜S8・ビート整列承認=align停止点）、

やること: どの発話を残すか（cutlist）＋どの画を当てるか（B-roll設計）。ここが編集の本体。

- 削除の単位は「無音に挟まれた発話の塊」。候補は `qc_speech_trim.py`
  （内容語が薄い／言い回しの再出現／相槌だけ）が出すが、**採否は人の判断**
- **裏側の会話に注意**（撮影者と演者の打ち合わせが混入する。18で6.4秒が採用版に入っていた）

- ★**併合してはいけない**: 断片カットを隣と併合すると間の無音が復活する
  （端の余韻0.09秒×2が加算。検品基準0.25秒を守るには隙間0.07秒未満のみ併合可）。
  断片は**挿入映像で覆う**
- B-roll設計は `SELECTION_PROTOCOL.md` の8段フロー（台帳→DB→フレーム目視→二重検証）＋
  `qc_inserts.py` の機械ガード（重なり／回数／再登場の近さ／タグ／尺1.5秒以上／**先出し**／隙間）。
  **設計スクリプトの末尾で検品スクリプトを必ず呼ぶ**（ガードと検品の項目をずらさない）
- 置いてはいけない場所: 実演中／指差し・視線誘導の最中。隠す前に下のA-rollを必ず見る

## [4] アセンブリ — DAGで一括生成

タイムライン固定 → 完成音声の再構築と再文字起こし → テロップ → SE・強調。
**1本のランナー（DAG）が依存を管理し、上流の変更で下流と検品を自動再実行する。**

> ★2026-07-30更新（テロップの正本とレンダーの分離・telop_mode）:
> - **telops.json（本文・時刻・スタイル・アニメ指定）はここで必ず確定**し、同期（words突合）・
>   幅（確定フォントの実メトリクス計算）・文節・誤字の機械検査もここで済ませる（レンダー不要の検査）
> - ★**様式の入力は参考分析の成果**: SE選曲の文法・テロップのフォント/px/入りアニメは
>   `style_profile.json`＋`telop_ledger.json`（TIMELINE-SHEET [R3.5][R5]）から流し込む。手癖で選ばない
> - `telop_mode: "premiere"`（プロファイル）の案件は**ここでテロップPNGをレンダーしない**
>   （入りアニメ=2Fフェード+スライド+方向ブラー等は静止PNGで再現不能。見た目は[8]でPremiereネイティブ投入）。
>   `"burnin"`（Remotion/ffmpeg納品案件）は従来どおりPNG生成

- ★尺が変わったら**全ての秒数を振り直す**。対応表を `qc/timeline_map.json` に残す
  （旧秒数のまま進むと削除区間へ挿入する事故が必ず起きる）
- **完成音声はテロップの唯一の入力**。窓分割（20秒窓・4秒重なり・中央優先）で文字起こしし、
  穴は元音声の語で埋める。★全文1パスは語を落とす（語間0.6秒以上の「穴」4箇所が
  全部実発話だった実績。穴は詰める前に**必ず単独で文字起こし**）
- ★whisperは語を作り・落とし・固有名詞を誤る。疑わしい箇所は区間切り出し＋単独文字起こし＋
  元音声突合で確定。訂正は**1文字ずつ時刻按分**。固有名詞が確定できなければテロップから外す
- テロップ: 文節頭のみで切る（数値＋助数詞・カタカナ複合語・一続きの述語は禁止境界）→
  `snap_telops_to_cuts.py` でカット境界へ（**ずらし優先・割り直しは退避**。逆順は0.1秒台の枚を生む）→
  実フォント幅（上限=画面幅×0.74）で折る。折り返しも文節頭のみ・退避路にも禁止境界を効かせる
- SE・強調: **本文の語でアンカー**（通し番号は枚数が変わると全滅する）。
  同じSEを続けない・間隔は最小1.35秒・強調は連続させない・語カテゴリでなく弧で決める

## [8] Premiere配置 ＋ タイムラインdiff

- ★★★**素材は切らずにトリムで入れる**（`_video-core/PRINCIPLES.md` §16・違反厳禁）。
  ffmpeg で `src_in`〜`src_out` を切り出したファイルを作って置かない。元素材を取り込み
  `setInPoint`/`setOutPoint`（**2引数**）を打ってから `overwriteClip`。前後がハンドルとして
  残るので、投入後に人が端を掴んで伸ばせる。**切り出すとこの自由が原理的に消える**
- ★トリムの検算に `outPoint` の読み戻しを使わない（**伸ばしても伸びない**）。
  尺は **`end − start`** で突合し、効いているかは**書き出した実ファイルの画素**で判定する
- 既存シーケンスを上書きしない（複製→新版）
- ExtendScript: 戻り値は常に"undefined"（結果はファイル経由）／evalは弾かれる（.jsx＋$.evalFile）／
  長いスクリプトは分割／日本語UIは `matchName` で指定（音量=Internal Volume Stereoの2番目）
- **B-rollのリンク音声がA2に流れ込みSEを消す**。配置後にA2をクリアしてSEを置き直す
- SEの音量は**開始時刻で照合**して当てる（順番だと断片1つで全滅）
- 配置後: 全トラックのクリップ数を設計値と突合＋A2末尾が総尺を超えていないか
- ★**タイムラインdiff**: シーケンスを読み戻して正本と突合。手編集（申告の有無を問わず）を
  機械検出し、取り込むか棄却するかを人に確認 → 取り込む場合は正本を更新して[4]から再実行
- ★telop_mode=premiere: 映像・SE配置後に**テロップを一括投入**する（2026-07-30新設）。
  入力は telops.json（正本: 本文・時刻）＋ telop_ledger.json（フォント実名・px造形・入りアニメ仕様）。
  `プレミアプロ_テンプレ/テロップシーケンス.prproj` のテンプレテキストを流用し、ExtendScript/手作業
  いずれでも**正本からの転記**として行う（Premiere上で文言・時刻を創作しない）

### A. DAGランナー `pipeline.py`

- **ノードと依存**:

  words/env（音声正本）
    → cutlist → timeline_map
        → final_audio → final_words → telops → snap → telop_png
        → broll（アンカーにtelopsが要る）→ qc_inserts
        → se（同上）

- **停止点は2箇所だけ**: [3]シート承認・[7]視聴承認。ランナーはそこで止まり「何が承認待ちか」を出す。

# 付録: ショート動画編集のコツ（出典つき）

数値の出典は `PACING-SOURCES.md`（URL・公開日・原文つき）。

## 1. フック（冒頭）

- 視聴者は **2〜3秒**で見続けるかを決める。**離脱の大半は0〜3秒**に集中
- 冒頭で **25%超**を失うとプラットフォームがリーチを絞る（"Hook Drop Delta"）
- **3秒残存率**が主要シグナル。3秒時点70%超でバイラル化しやすい
- **名乗り・挨拶・前置きから始めるのが最も完視聴率を下げる**
- 30秒なら フック0〜3秒 ／ 本編3〜25秒 ／ CTA25〜30秒
- ★**「答えを先に出す」を機械的にやらない**。問いかけの最中に答えの画を出すと会話として不自然
  （実証済み）。先出しは**内容の一致**であって**時間の前倒し**ではない

## 2. カットの尺・視覚変化の密度

| 項目 | 値 |
|---|---|
| 視覚変化 | **10秒あたり5〜7回**（4回未満は間延び／8回超はノイズ）|
| 1カット | 2〜4秒 |
| 冒頭0〜5秒 | 1秒前後で刻む |
| 挿入映像 | 1.5〜3.0秒 |
| **認識の下限** | **1.2秒**（これ未満は脳が処理できない）|

「視覚変化」に数えるもの: カット／カメラの動き／テロップの差し替え／ズーム／色の変化／リビール。
★**編集回数ではなく刺激の密度**（"a slow push-in can replace a cut"）。
カットを増やせない区間（実演中など）はズームとテロップで密度を作ってよい。

## 3. 歯止め

- **ペースは物語に従う。話が運べる以上に速く切ると逆効果**
- 統計ゲートは**落第検出専用**。合格判定には使えない（Goodhartの法則）。
  数値のために「言葉を言い切らせる」等の恒久禁止を破らない

## 4. テロップ

- 焼き込みテロップは完視聴率を上げる。位置は固定（画面の約53%）
- 幅の上限は**画面幅×0.74**。収まるなら1行
- **数字情報は最低1.5秒表示**。1カットに主語は1つ
- 最終テロップは「最終フレームまで保持」の相対指定

## 5. 構成（実案件で効いた型）

```
掴み … 商品が即登場し、最も強い数字（価格）で殴る
谷   … 弱点・不安の提示。音も画も抑える
上り … 装備・良さの列挙。リズムを作る
山   … 弱点を自分から言い出す（正直さが信頼になる）
オチ … 弱点を強みに反転させて締める
```

- **谷を作るから山が立つ**。前フリ・列挙・つなぎは意図的に「抜く」
- CTAは1本に絞る。同じCTAが2回あれば片方は削る
- 締めに店舗名・価格POP・展示場の画を1回。CTAまで色とフォントを統一

## 6. 素材が足りないときの現実解

- 使用回数の上限を上げる（2→3）。ただし同一区間の使い回し禁止・再登場は間隔を空け・
  **被写体が違う窓**を選ぶ
- 切れている窓・画質の悪い窓は不採用として焼き込む。回数稼ぎに使わない
- それでも足りなければ**置かない**。無理に置くと重複感で逆効果
- 足りなかった事実と理由を記録し、次回撮影の申し送りにする
