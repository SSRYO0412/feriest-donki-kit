# テンポ判定（5段階・スカラー禁止）

> 原則: テンポは「時間の中の形」。中央値・平均・分あたり本数という**スカラー1つでの合否判定を禁止**する。
> 参考動画は掴みで刻み、見せ場で溜め、オチで切る——その**形**を照合する。

## なぜスカラーではだめか（実例）

過去の失敗: ショット尺の中央値が参考比+40%外れたが「1指標だけ外れ」として通した。
実際には序盤の同じ画が続きすぎており、視聴者体験としてテンポが悪かった。
逆に、しきい値を下げて機械的に細かく刻んでも中央値はほぼ変わらず、
「語の途中で切る」という上位禁止事項と衝突しかけた。**合わせる対象が間違っていた。**

## 5段階判定（全て順番に、全対象区間について行う）

### ① 機械で実測
- 参考と出力の両方で「正規化位置に対するショット尺の並び」「テロップ密度の推移」「SE密度の推移」を出し、**形として照合**する
- フレーム差分で「**画が実質変わっていない秒数**」を全区間で実測（qc_machine.py の no_change 検出）
  - 挿入映像を跨いでも被写体が同じなら「変わっていない」と数える（開始点をずらしただけの画は目には同じ）
- 種別上限（video_profile.json）を超える区間を全て列挙する

### ② 目視で確認（Codex＋Claude の両方）
- 列挙された区間を実際に見て「同じ画が何秒続いて見えるか」を確認する
- 数値では「別カット」でも目には同じ画に見えることがある（実例: Codexの全数レビューが「s004〜s014は見た目がほぼ同じで序盤の画変わりが弱い」と検出。機械検算はすり抜けていた）

### ③ 妥当性を判断する（長い＝悪い、ではない）
判断軸は4つ。全て記録する:
1. **動画の種類**: 縦型ショートは指で送られる前提→画が変わらない時間の許容が短い。横型・長尺なら伸びる
2. **内容**: 数値・スペック提示は短く／実演（手を動かしている）は長く許容／オチ・溜めは意図的に長くてよい
3. **前後の意味の繋がり**: 直前の画と意味が連続しているか。切り替えると文脈が切れないか
4. **テロップとの関係**: テロップが切り替わるのに画が止まっていないか。画だけ動いてテロップが取り残されていないか

### ④ 妥当でない場合、他素材を全時間窓から探す
- その区間に置ける候補を**全素材の全時間窓**（目視済みラベルのみ。未確認の窓は使用禁止）から列挙
- 5候補をスコアリング（内容一致/寄り引き/新鮮さ/尺/画質、被写体タグ重複は減点）

### ⑤ 候補が無い場合の5択（「無いからそのまま」は禁止）
全てをスコアして最良を選ぶ。選ばなかった選択肢のスコアも記録:
- (a) 既存素材からデジタルズーム／クロップで**別の画を作る**
- (b) 主映像に戻す（話者の画で持たせる）
- (c) 尺を詰める（その区間の発話を削って短くする）
- (d) 前後のカット配分を変えて、その区間の長さ自体を減らす
- (e) そのまま残す — **この場合のみ理由を記録し、Codexの承認（codex_approval）を得る。承認なしの(e)は無効**

## 設計側への要求（検品で検査する項目）

- カット表に `section`（掴み/展開/山/締め）と `pace`（加速/等速/溜め）が**全区間で埋まっている**こと。空欄はFAIL
- 「ここは加速」「ここは溜め」の意図が書けないカット表は、テンポを設計していない証拠

## tempo_report.json の形式

```json
{
  "profile": "vertical_short",
  "no_change_limit_sec": 2.5,
  "segments": [
    {
      "start": 80.37, "end": 90.43, "no_change_sec": 10.07,
      "step2_seen": {"codex": "qc/codex_view/frames_03.json", "claude": ["qc/frames/f2411.jpg", "qc/frames/f2650.jpg"]},
      "step3_judgement": {"type_ok": false, "content": "実演ではなく感想の連続", "context": "直前と同一被写体", "telop": "3枚切り替わるのに画が静止"},
      "step4_candidates": [ {"src": "...", "window": [3.4, 4.8], "score": 90, "tempo_impact": -5.6, "seen": ["..."]} ],
      "step5_choice": null,
      "selected": {"kind": "insert", "src": "...", "why": "..."}
    }
  ]
}
```
- (e)を選んだ場合は `step5_choice.codex_approval` にCodex応答の保存パスを必須で入れる。
