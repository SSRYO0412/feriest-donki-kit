## 原則

1. **1行=1秒**。フレーム級の出来事はサブ秒イベントとして行内に記録（2階建て）
2. **確定/推定を列で区別**。prproj由来・機械実測＝確定、AI所見＝推定（裏取り後に確定へ昇格）
3. **prprojがあってもAI分析は省略しない**（prprojは「何をしたか」、意味と意図はAI＋人）
4. **agy仮説→Codex検証→機械/prproj突合→人が裁定**の検証チェーン。一致だけが「実測済みの癖」
5. 視覚作業は **agy×Codex同時起動・並列上限**（インジェストv3と同じ厳守。agy16/Codex20）
6. 編集意図・肝の確定は**人（Claude）のみ**が書く

## 三者の分担（詳細）

**agy（時間の連続体）**: パン/ズームの開始終了と加減速の質感／音×映像の同期（SEがどの視覚イベントに
当たるか・発話のどこで切るか）／連続描写ログ（等速＋0.25倍速の2パス）／編集意図の一次仮説／
視聴体験の主観（どこで飽きるか）。時刻はファジー→正は機械/Codex/prproj。

**Codex（フレーム精密・基本4枚/秒＋遷移±0.5秒は30fps全コマ）**: agy仮説の裏取り（座標・フレーム番号で
数値化）／テロップ全要素＋**出現アニメの実測**（縦潰れ/フェード/popの所要フレーム数）／構図の精密
（被写体サイズ比率・画面内座標）／絵変わりの実体（カット前後の対比: 色/明るさ/サイズ/方向）／
意味差分（inventory差分で新情報の入った瞬間）。

**人（Claude）**: 3点照合と食い違いの裁定（conflict駆動）／編集意図列の確定／定石との照合
（PACING-SOURCES.md を**再調査で更新してから**）／肝TOP3の確定と判断文法への昇格。


## prprojがある場合（確定＝正典データ）

ExtendScript/Premiere MCPで全数ダンプ:
- 全クリップ in/out/トラック/速度 → カット構造フレーム精度確定
- source in/out → **素材のどこを選んだかという選定の癖**
- スケール/位置キーフレーム → パンチイン/ズームの実カーブ（倍率・イージング）確定
- テロップクリップ・MOGRTプロパティ／SE（ファイル名・時刻・**音量dB**・フェード）／
  BGMオートメーション（ダッキング実体）／タイムリマップ
prprojはAI時刻の校正基準。CodexはprProj操作の「見た目の効き」検証へシフト。

## prprojがない場合（他人のバズ動画）

カット境界=機械+Codex裏取り（確定）／カメラ数値=フロー実測（確定）／
パンチインvsカット=フローの瞬間ジャンプ+同一絵の拡大判定（確定）／
テロップアニメ=遷移全コマのCodex読み（確定）／SE時刻=オンセット検出（確定）／
SE種類=agyが聴いて同定（推定）／SE音量=RMS差分（推定）／BGM=agy記述+エネルギー曲線（推定）。
クローン時: 確定値は完コピ・推定値は±幅を持って再現。

## [R3.5] 完全再現レベルへの昇格手順（07具志さん2で確立・2026-07-30）※旧記載[R6]はパイプラインのverifyと重複のため改番
シートを「同じ素材で1:1再現できる」レベルにするには、[R3]の後・[R4]の前後で以下を必ず行う。Codex敵対検証で「概ね十分」判定を得た実証手順:
1. **フォントは prproj から直接抜く（目視照合だけで確定しない）**: `scripts/extract_prproj_fonts.py <prproj> <telop_fullread.json>`。prproj(gzip XML)のソーステキストblobからPostScript名を抽出し、本文突合で動画単位に絞る。※実証: 目視照合の初期候補（源真ゴシック/凸版文久明朝）は両方誤りで、正解はNotoSansCJKjp-Black/SourceHanSerif-Heavyだった。目視のみのフォント特定は禁止（telop-analysis-methodology 12節に恒久化済み）
2. **テロップpx実測**: `scripts/measure_telop_px.py <telop_full_dir> <out.json>`（fill/縁色/字高/中心座標）。白マスクは**黒フチ判定（周囲リング輝度<110）必須**（空・白車が混入する。ガード内蔵済み）
3. **音声全数ダンプ**: `scripts/dump_audio_tracks.jsx`（Premiere MCP execute_extendscript で実行）で全音声クリップの path/level/pan を取得。level 0.177827=0dB / 0=ミュート。「VO差し替え区間はA-roll音声をlevel=0」のような運用が見える
4. **fpsはticksから確定**: 254016000000÷frameRateTicks。時刻値の刻みからの推定は誤る（1/30刻みに見えて実は60fpsだった実例）
5. **入りアニメの全数内訳**: キー持ち=keyframes.jsonのkeys / キーなし=開始0Fの文字マスク面積比で「即時全表示」を機械確定（面積比>0.85=フェードなし）。背景差分では判定不可（A-rollの動きを拾う）
6. **統合台帳 telop_ledger.json を必ず作る**（scripts/build_telop_ledger.py）: 本文+px+フォント+入りアニメ+キーをfile名キーで1レコード化。分散したままだと再現時に迷う（Codex指摘）
7. 最後に **Codexへ「この資産だけで1:1再現できるか」の敵対検証**を投げ、指摘を裁定→埋めて再検証
