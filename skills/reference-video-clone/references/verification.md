# 多重検証の重ね合わせ（4層・stackして初めて合格）

ある編集判断は **次元内 ∧ 次元間 ∧ 情緒整合 ∧ 多重サンプリング** を全部通って初めて採用。
敵対的検証を次元横断でやる。1観点で満足しない（空間重なりの見逃し前科あり）。

## 層1：次元内検証（各次元が自分の正しさを満たすか）
| 次元 | チェック | ツール |
|---|---|---|
| テロップ | 音声同期≤0.3s / 消し忘れ(caption end≤clip dur) / 空間重なり / 語中切れ / **全要素パリティ（1.7節）** | `check_overlap.py`, スクショ目視 |
| カット | 切り位置が語境界±0.15sに乗っているか / ジャンプの破綻なし / **逐語照合（1.5節）** / **密度が参考±30%（1.6節）** | クリップ頭末フレーム、`window_transcribe.py`、`verify_tempo.py` |
| SE | 配置時刻がビート頭±0.15s / 谷に誤爆なし / **SE数/分が参考±30%（1.6節）** | `analyze_se_motion.py`, `verify_tempo.py` |
| 間 | 詰め/溜めが尺崩壊を起こしてないか / A-V同期維持 / 変速クリップのピッチ・字幕同期 | 尺ドリフト測定 |
| フレーミング | capture-limited素材(shots=1)に謎ズームを足してないか / 寄りが主役を外してないか / 同一ショットのスムーズズームが無いか | `detect_shots.py`＋フレーム目視 |

### 1.5 カット境界の逐語照合（★必須・文の途中で切れていないかの最終確認）
編集の良し悪し（締め/抜き）はeditorial-analystの判断領分だが、**「使うと決めた発話が、語の途中・文の途中でぶった切られていないか」は機械的に検証可能な事実**であり、必ずチェックする。
1. 完成カット `out/final.mp4` を `transcribe.py` でフルパス文字起こしする（= 完成版の実際の語境界）。
2. 各クリップについて、Phase2で取得済みの元素材 `work/words.json`（`window_transcribe.py` による局所窓・単語単位タイムスタンプ）と、`edl.json` が指定した in/out 点を突き合わせる。
3. 各 in点・out点が以下のどちらかになっているかを確認する：
   - **文/節の境界**（句点・読点・助詞の切れ目）に乗っている、または
   - editorial-analystが意図的に途中で切って別演出（テロップで言い換え/要約）に繋いだことが arc.json / edl.json に明記されている
4. 上記いずれでもない場合＝**語の途中 or 文の途中での意図しないカット**として即 FAIL。該当クリップの in/out を `words.json` の単語境界に合わせて edl.json を修正し、再カット。
5. 完成版の文字起こし結果と「使うと決めた発話（words.json の対象スパン）」を文字単位で diff し、**脱落（言い切れていない語）・重複（同じ語が2回入る）・誤接続（文法的に繋がらない語順）**がないかも確認する。
6. 1点でも不一致があれば層1 FAIL として差し戻す（推測で「たぶん大丈夫」と判定しない。必ず実際の文字起こし結果同士を突き合わせる）。

### 1.6 テンポ・密度ゲート（★必須・「編集されていない」印象の機械検出）
静的な見た目が合っていても、**時間軸の編集量**が参考から乖離していると納品NGになる
（実証: カット/分が参考の1/5・31秒ノーカット・SE 6発vs28発の出力が「これで依頼するのは厳しい」と差し戻された。
先方の合格版は全指標が参考の±35%以内だった）。
1. `verify_tempo.py out/final.mp4 <参考動画>` を実行（2回目以降は `--save-ref` した ref_stats.json を渡す）。
2. 照合5指標: **cuts/min・ショット長中央値・最長ショット・テロップ遷移/分・SE/分**。
   PASS=参考±30%（テロップは±40%）/ 最長ショットは参考×1.5+0.5s 超で即FAIL。
3. FAIL が1つでもあれば差し戻し（EDLのカット粒度・変速・seEvents を設計し直す）。
   WARN は「参考との意図的な差」の根拠を明記してユーザー承認を得た場合のみ通過。
4. 注意: ショット検出は**複数閾値スイープ**（detect_shots.py 既定）。単一閾値0.30の値で
   「参考もカットが少ない」と誤読しない（ジャンプカット4割取りこぼしの実証あり）。

### 1.7 テロップ全要素パリティ（★必須・参考と同ビートの横並び照合）
テロップの**形態は参考ごとに別物**。`telop-analysis-methodology.md` 15節のチェックリスト
（デザイン/サイズ・位置/タイミング/改行・意味単位/動的様式）を、参考と出力の**対応ビートの
フレームを1枚ずつ個別に横並び目視**（montage禁止）して全要素一致を確認する。
1要素でも差があれば修正→再照合を識別不能レベルまで反復。参考に無い要素を足さない・ある要素を省かない。

### 1.8 知覚ゲート（★最終合格判定・editor-in-the-loop。統計ゲートの上位）
**統計ゲート（1.6節）は落第検出専用の必要条件であり、合格判定には使えない。**
実証: v2案件で「カット検出数値を通すため」に隣接クリップへ機械的なズーム交互(1.0⇄1.08)を入れた出力が、
verify_tempo 全項目PASSのまま「そもそもカット編集がダメ」と差し戻された（指標を攻略すると
指標は品質の代理でなくなる=Goodhartの法則）。数値が良くても知覚品質は別（PRINCIPLES 閉ループ選別の原則）。

合格は以下を全て行った上でのみ宣言する:
1. **全カット境界の個別検分**: 各境界の前後フレーム列（±5フレーム程度）＋音声を1箇所ずつ見て聴く。
   チェック: 等間隔スライス感がないか／ズーム切替に動機（判定・キー句・切り返し・リアクション）があるか／
   変速の継ぎ目で声のリズムがガクついていないか／切りが「言い終わり・意味の節目」で呼吸しているか。
2. **全テロップ出現の動き照合**: 出現を静止画でなくフレーム列で見て、参考の実測（立ち上がり・pop・
   発話同期・意味単位）と一致するか確認。
3. **通し視聴**: 全編をフレーム連続＋音声セグメントで検分し、違和感を全て列挙→ゼロになるまで修正反復。
4. 制作した本人の検証は甘くなるため、少なくとも1回は**敵対的視点**（「これは機械が編集したように
   見える箇所を探せ」）で通す。
スチルのみ・数値のみで「検証済み」と言うのは禁止（v2の失敗様式そのもの）。

### 1.9 意味整合ゲート（★談話としての通読・逐語照合とは別物）
逐語照合(1.5)は「語が壊れていないか」しか見ない。**組み上がった台本が会話として意味が通るかは
別の検証**であり、必ず行う（実証: 逐語クリーンなのに「意味が繋がっていない・会話の途中で途切れる」
と差し戻された——Qと噛み合わないA・宙に浮いた指示語・列挙の途中からの開始）。
1. EDL確定時: 採用スパンのテキストを順に並べ、**物語として頭から通読**。チェック: 指示語/接続詞の
   先行詞が画面内にあるか／Q→Aが噛み合うか／前提→帰結が揃うか／文中から始まる・終わるクリップがないか。
2. 完成版: final の文字起こしを同様に通読し、1で通した意味が実映像でも成立しているか確認。
3. 断絶が1つでもあれば選定を修正して再ゲート。これはLLMの読解で行える検証であり、省略の言い訳はない。

### 1.10 精読プロトコル（★毎回・納品前・成果物必須）
ユーザーが精読役になっていた学習ループを内製化する。**レポートファイルなしに「検証済み」を名乗れない**。
1. **機械パート**: `check_atom_integrity.py`(アトム境界の切り詰め禁止・手打ちio拒否) →
   `check_clip_text.py`(クリップ単体を再ASRし**アトムDBのtextを正**として期待テキストdiff —
   words.jsonの穴に影響されない) → 既存ゲート群(談話/境界エネルギー/snap)。
2. **読みパート**: 完成版全文を台本として通読し、クリップごとに構造化質問表
   〈前提は**音声で**既出か/文中(頭だけでなく)の指示語の参照先/終止形か/次クリップへの受け渡し〉に
   **文字で回答**する。頭の中で済ませない(暗黙の通読は3回劣化した実績)。
3. **第三者パート**: 文脈を持たない別エージェント(Codex等)に台本だけ渡し
   「意味が繋がらない箇所を全て挙げよ」と敵対的に読ませる(自己審査の甘さ対策・実証3回)。
4. 全所見を `out/seidoku_report.md`(時刻・分類・判定=欠陥/ASRノイズ/承認)として保存。欠陥ゼロまでループ。
5. **精読で見つけた新種の欠陥はその場でリンター/ルールに昇格**(学習ループの内製化)。
関連する構造ルール: 取り込み時に `check_db_holes.py`(音声あり語なし帯の列挙→窓転写で充填)、
EDLトリムが必要な時は**DB側でアトムを分割・再検証・登録してから**(EDL側の即席トリム全面禁止)。

## 層2：次元間整合（収束と静粛）
- **山の収束**：各 `締強` ビートで、何次元が発火しているか数える。**3次元以上**で「立っている」と判定。未満は弱点として記録。
- **谷の静粛**：各 `抜` ビートに強演出（衝撃SE/過剰な寄り/締強）が混入していないか。
- 例：判定オチが「テロップだけ大きくてSEもカットも普通」なら山が弱い＝差し戻し。

## 層3：情緒整合（参考の弧の形を再現しているか）
- **山谷の配置**：素材の弧が、参考と同じ〈谷→上り→山〉のリズムを持つか。
- **トーンの描き分け**：複数の判定/オチが互いに違う顔か（全部同じ＝浅い）。
- **締めは弧に1つ**：締めすぎ（山が連続）していないか。
- **ギャップが立っているか**：好奇心の駆動（矛盾）が各弧で機能しているか。

## 層4：多重サンプリング（測定値の確度）
- 色・SE・サイズ等の **実測値は N≥3 で確定**、N==2 暫定、N==1 単発（ルール化しない）。
- **反例スキャン**：ルールが破れる例を能動的に探し、条件を磨く。
- 帽子オレンジ・木目・UIの混入ガード（色は機械値を鵜呑みにせず目視）。

## 合否（★満点ゲート・ラウンド上限なし）
- 層1〜4を**重ね合わせ**、全層**100%通過**で納品。1層・1項目でも WARN/FAIL があれば差し戻し（specialist or editorial-analyst へ）。
- **部分合格・「だいたいOK」は不可**。スコア化する場合は全項目PASSで100点、1項目でもWARN/FAILがあれば100点未満＝未納品。
- 差し戻し→修正→再検証のループを、**全層・全項目が100点になるまで何度でも繰り返す**。ラウンド数の上限は設けない。同じ箇所が連続で割れる場合のみ、原因（測定ノイズ/実バリエーション/設計ミス）をユーザーに報告し方針確認する。
- 最終ゲート：**知覚ゲート（1.8節・合格判定はこれのみ）** ＋ 全テロップ・全ビートのスクショ目視 ＋ 山の収束度レポート ＋ カット境界の逐語照合レポート（1.5節）＋ テンポ・密度ゲートレポート（1.6節・落第検出用）＋ フォント完全一致確認（`references/telop-analysis-methodology.md` 12節）＋ テロップ全要素パリティ（1.7節・15節チェックリスト・動き込み）。
- 検証結果は毎ラウンド記録し、何が直って何が残っているかを明示する（「変化なし」のような曖昧な報告をしない）。

## ★完コピ検証層（型完コピ系スキルのみ適用: faceless-video-clone / faceless-person-swap-clone / faceless-person-swap-faithful / lp-beforeafter-material）
型（尺/位置/UI）を参考からそのまま複製したかを照合する。**記憶近似で納品しない＝必ず参考と並べて diff を見る。**
- **尺一致**: 出力の段切替時刻が参考の clone-spec と一致（`compare_cadence.py` で数値照合±0.2s / `extract_timeline.py` で目視照合）
- **位置一致**: テロップ/UIの位置が参考と一致（`overlay_diff.py` で出力フレーム↔参考フレームの領域MAE）
- **UI再現diff（条件付き=UIがある時のみ）**: 質問スタンプ等のカード領域を `overlay_diff.py` で照合（構造・色・フォント・位置）。UIが無い動画ではスキップ。
- **パーツ変化の確認**: 背景/人物が前回と固定でなく毎回生成され、スタイルが変わっていること（量産バリエーションの担保）。※忠実再現系（faithful/lp）は逆に「人物以外が参考のまま保持されているか」を照合する。
- 9分割×上下反転 overlay・全フレーム照合などの詳細手順は各スキルの SKILL.md Phase 4.5/5 に従う。
