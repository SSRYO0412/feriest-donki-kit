# トーン語彙ライブラリ（育てる資産）

editorial-analyst が各弧のトーンを選ぶ辞書。各 specialist は自分の次元の推奨プリミティブをここから引く。
**参考動画を分析するたびトーンと演出が増える＝「センス」の蓄積。** 1動画固有の語彙でなく、情緒タイプとして抽象化して登録すること。

各トーンの形式：
- **情緒の定義**：その感情が何か
- **見分け方**：会話のどんな兆候で判定するか
- **推奨プリミティブ（次元別）**：telop / cut / se / pace / framing

---

## バッサリ（容赦ない即断）
- **情緒**：迷いなく切る潔さ。速さと断定が笑いになる。
- **見分け方**：欠点が明白／即座に結論／短い判定語。
- **推奨**：telop=`締強`＋`温度:white`（中立判定語を最大化） / cut=`余韻ホールド`（切った後の表情） / se=`衝撃:強`（弧の初回オチに最強を温存） / pace=`溜め`→即`締強` / framing=`寄り`（判定者へ）

## 温かいYES（大人の納得）
- **情緒**：安心・納得の肯定。殴らず受け止める。
- **見分け方**：経験/強みへの言及／好意的な品定め／条件付き肯定。
- **推奨**：telop=`立:キー句`＋`温度:red`（決め手の理由を隔離）, 締めは`締柔`（大判定語は出さない） / cut=`提示カット`→`切り返し` / se=`衝撃:中`or`無音` / pace=`標準` / framing=`引き`→`寄り`

## 切ない優しい否定
- **情緒**：突き放さない否定・申し訳なさ・残念さ。
- **見分け方**：好印象→構造的なすれ違い／「うちじゃない方が」等の婉曲。
- **推奨**：telop=**`締柔`（大判定語をあえて出さない・文を柔らかく残す）** / cut=`余韻ホールド`（長めに表情を残す） / se=`無音`（殴らない） / pace=`溜め`（急がない） / framing=`寄り`（共感）
- ★注意：バッサリと **絶対に同じ処理にしない**。情緒が逆。

## 誠実な熟慮（重い/タブーなテーマ）
- **情緒**：茶化さず慎重に線引きする真面目さ。
- **見分け方**：前科・センシティブ語の登場／「〜による」「何ならOK/NG」と条件を探る。
- **推奨**：telop=`立:キー句`（思考＝線引きを可視化・**色で茶化さず白基調**）, 着地は`立:キー句`＋`温度:red`（寛容な決め台詞） / cut=`切り返し`（熟考の表情） / se=`衝撃:中`（テーマ登場の重み） / pace=`溜め` / framing=`寄り`（真剣さ）

## 期待→肩透かし（コミカルな落差）
- **情緒**：上げて落とすお笑い。期待値を作って裏切る。
- **見分け方**：華やかな属性/容姿で期待up→「〜だけど」で反転。
- **推奨**：telop=上げ＝`立:キー句`＋`温度:yellow`（煽り）, 落ち＝`締強`（大判定で落差） / cut=`溜めカット`→`余韻ホールド` / se=上げ＝`煽り:明`, 落ち＝`衝撃:中` / pace=`溜め`（オチ前で一拍） / framing=上げ＝`寄り`, 落ち＝`引き`（はしご外し）

## 本音・歓迎（締めの誘い）
- **情緒**：判定モードを抜けた本音・親しみ・招き入れ。
- **見分け方**：理想像の列挙→「〜なら僕はいい」／呼びかけ。
- **推奨**：telop=列挙は`抜`（谷）, 本音の一文＝`立:キー句`＋`温度:red`, CTA＝`温度:red`面塗り / cut=`提示カット` / se=`衝撃:中`（決め台詞） / pace=列挙`標準`→締め`溜め` / framing=`引き`（場全体・安心感）

## 物販実演UGC トーン（案件V黒スニーカー参考から追加 / 2026-06）
※既存トーンは面接・品定め系で物販実演に非対応のため新規5トーン。値は参考実測ベース、別参考では再測定。

### 開封の所有感（高級感のつかみ）
開封の一瞬で所有欲・第一印象の高級感を立てる掴み。色や煽りでなく余白と質感。見分け=冒頭の開封/初見/逆説(高級感なのにロゴ無し)・短い断定句。
推奨: telop=立:キー句＋温度:white(明朝の白) / cut=提示(最長shotで掴む)→寄りディテール / se=衝撃:強(開封初撃に最強＝温存の基準点) / pace=標準 / framing=寄り(手元・ロゴ)

### 体感の実演（柔↔バネの落差）
相反する二体感(沈む=柔/離れる=バネ)の落差で機能を気持ちよく見せる。見分け=動作実演＋二段構成・比喩で頂点。
推奨: telop=設定:抜/頂点:立:キー句(比喩を改行隔離) / cut=前段:提示短尺/頂点:余韻ホールド / se=前段:無音/頂点も素材無音→出力時に衝撃:中まで(USP未満) / pace=前段:詰め/頂点:溜め / framing=寄り(ソール接地/離地)

### ポジティブ・どんでん（正体開示）★最重要
『普通』で一旦落としてから正体(USP数値)をぶつける、上げでなく落として跳ねる逆ドラマ。見分け=『〜なのに』で宙吊り→数値/正体で回収・最も引いた画→寄りパンチイン。
推奨: telop=タメ:抜(語で吊る)/開示:締強(数値を確定行頭) / cut=溜めカット→余韻ホールド / se=タメ:衝撃:中(音色で予告)/開示:衝撃:強(全編2番手) / pace=タメ:溜め(谷でも溜め優先)/開示:溜め / framing=タメ:最も引く/開示:相対パンチイン

### 万能の畳み掛け
用途を最速で畳み掛け、直後に長回しで緩める速→緩の説得。見分け=シーン語列挙(三点リーダ)→一文回収・最速カット連発→最長hold。
推奨: telop=列挙:抜(均一・一語強調しない)/回収:締柔 / cut=圧縮ジャンプ→余韻ホールド(最長hold) / se=列挙:衝撃:中(低z刻み)/回収:衝撃:中(節目) / pace=列挙:詰め/回収:溜め / framing=列挙:引き〜中/回収:中寄り

### 余裕の社会的証明とブランド着地
第三者の声で見返りを示し、ブランド名で全伏線を束ねて静かに締める。見分け=鉤括弧の引用→ブランド名＋『正体です』で円環回収。
推奨: telop=証言:立:キー句(記号で隔離)/着地:締強 / cut=長回し溜め→本編最寄りへハードカット / se=証言:衝撃:中/着地は素材無音→出力時に締めSE推奨 / pace=証言:標準/着地:溜め / framing=中寄り維持→本編最寄り(冒頭ロゴ寄りと対)

## 物販実演UGC 追加トーン（案件V 身長直球型UGC参考から追加 / 2026-06）
※物販実演UGCの「悩み名指し冒頭」と「体験談ドラマ」に既存トーンが無かったため新規2トーン。値は参考実測ベース、別参考では再測定。

### 悩み名指しのフック（自分事化のつかみ）★冒頭専用
視聴者の悩み(身長/体型/年齢等)を冒頭で直接名指しし『これは私の話だ』と自分事化させてスクロールを止める掴み。煽りでなく当事者の一点撃ち。見分け=冒頭の二人称＋具体数値(『身長169cmのあなた』)・同一テロップを複数カット反復・直後に低姿勢の誘い(『お願い聞いてください』)で警戒を解く。
推奨: telop=名指し句=立:属性＋温度:white(数値を最大化)/誘い=締柔(命令にしない) / cut=提示カット反復(同テロップを複数カットで刺す) / se=冒頭=明るいSE(whoosh/ding)で停止合図/誘い=無音 / pace=名指し:標準〜やや溜め/誘い:標準 / framing=引き(全身=身長の文脈を見せる)→軟着陸で中寄り
- ★注意：これは「上げ」でなく「刺す」。期待→肩透かしと違い落とさない。誘いの一文は殴らず締柔で受ける。

### エピソードの自信獲得（体験談ドラマの温度）★物語の締めは締柔
第三者の声→内面変化→波及を順に積み、数値や開封と違う『物語の温度』で殴らず着地する体験ドラマ。見分け=他者の生セリフ(鉤括弧)→一人称の実感→『自信』等のキーワード反復で積み上げ→静かな到達文で締める。
推奨: telop=他者の声=立:キー句(引用隔離)/実感の転換=立:キー句/反復の積み=抜(均一)/着地=締柔(大判定語を出さない) / cut=導入:提示短尺→声:切り返し→積み:圧縮ジャンプ→着地:余韻ホールド / se=導入:無音/声:衝撃:中(承認の節目)/着地:素材無音(殴らない) / pace=導入:詰め/積み:詰め/着地:溜め / framing=引き(エピソードの状況)→着地は中寄り(内面に寄る)
- ★注意：着地を締強にすると体験談が嘘くさくなる。ポジティブ・どんでん(数値の衝撃)/余裕の社会的証明(数値の確定)と **必ず違う顔** にする＝同じ動画内で数値山(締強)と物語山(締柔)を描き分ける。

## 感情ストーリー型 追加トーン（案件V身長コンプ縦型UGC参考から追加 / 2026-06）
※感情ストーリー型(共感→転換→解決)の「慰めから具体策への転換」「装着体感の連鎖」「希少性の緊急煽り」が既存に無かったため新規3トーン。冒頭の痛点掴みは既存「悩み名指しのフック」を流用(本参考は過去の自分への語りかけ＋慰めという切ない変奏だが、刺す→締柔の形は同型)。数値証明の山は既存「余裕の社会的証明」を流用(本参考は冒頭『自信なくさなくていい』が『自信がついた』で円環回収＝感情ピークだが、94%等の数値根拠を伴うため数値山=締強で扱い、物語山=締柔の体験談トーンとは描き分ける)。値は参考実測ベース、別参考では再測定。

### コンプレックス解決の希望（慰めから具体策への転換）
寄り添いの直後、等身大の自己開示＋具体数値で「あなたにも効く」希望を立てる転換。慰め(谷)を実証(上り→山)に変える橋。落とさず上げるのでどんでんとは別。見分け=自分の数値開示(『169cmの僕が』)→低コスト強調(『靴だけで』)→ベネフィット数値(『+6.5cm』)。
推奨: telop=自己開示:立:属性/低コスト:立/数値:締強(数値を行頭に確定)・余韻ベネフィットは立 / cut=提示カット→寄りディテール(足元/比較) / se=数値開示に煽り:明(希望の上げ) / pace=標準→数値前に軽い溜め / framing=引き(全身で身長文脈)→寄り(足元の数値根拠)

### 装着で世界が変わる連鎖（体感→他者反応の上り）
「履いた瞬間→自分の変化(姿勢)→他者の反応→決定打」と内→外へ連鎖させ、靴一足で世界が変わると確定する上りビート。長回しや連続上りで勢いを作り、最後の他者承認を山にする。見分け=即効性語(『瞬間から』)→内的変化(『姿勢が変わって』)→他者視点(『反応が』)→確定オチ(『明らかに違う』)。
推奨: telop=各段:立(均一に重ねる)/確定オチ:締強 / cut=提示→切り返し(自分→他者)→確定でハードカット(長回しへ) / se=始動と確定に煽り:明〜衝撃:中(連鎖の節目) / pace=詰め(テンポで勢い)→オチに軽い溜め / framing=引き(全身/姿勢)→反応抜き(他者・周囲)

### 希少性の煽り（緊急性）
社会的証明を「人気すぎて手に入らない」恐怖に転用し、安心トーンから一転して急かす。CTA直前の点火。安心(返品/保証)の谷の直後に置くと落差で効く。見分け=『試す人が多すぎて』→『一部のサイズが』(自分事に絞る)→『製造追いついてない』(品薄の確定)。
推奨: telop=需要過多:立/自分事の不安:立/品薄確定:締強 / cut=圧縮ジャンプ(畳み掛け)→UI/在庫画面提示 / se=各段に衝撃:中(刻んで焦らせる) / pace=詰め(急かす) / framing=中〜寄り(商品/在庫UIに寄る)
- ★注意：直前の「ブランド着地(安心)」と同じ顔にしない。安心は谷(抜)、希少性は急かす上り。トーンを切り替えることで落差が緊急性になる。

## 物販実演UGC 追加トーン（案件V 黒スニーカー品質比較型UGC参考から追加 / 2026-06）
※品質比較型(良品↔粗悪の対比＋素材/色訴求)で頻出。既存に「対比実証」「メタファー昇格」「欠点反転」「中毒断定」が無かったため新規4トーン。値は参考実測ベース、別参考では再測定。

### 比較実証（良品↔粗悪の対比）★品質比較型の核
良い側を最初に立て、すぐ後に粗悪側を『あえて引いて』見せ、落差で良品の質を体感させる。上げて落とすのでなく、良(山)→悪(谷)で良の輪郭を出す。見分け=『良い○○は〜／安い○○は〜』の対句・指/手の実演・一方は満足ワード一方はネガワード。
推奨: telop=良:締強＋温度:white(品質ワードを最大化)/悪:抜(ネガを殴らず地の文) / cut=良:提示(実演を最長で見せる)→悪:対比カット(同アングルで素材違い) / se=良:衝撃:強(冒頭の掴みに最強を温存)/悪:無音(引く) / pace=良:溜め/悪:詰め / framing=寄り(指・接地面のディテール)
- ★注意：悪い側にSEや寄りを乗せて殴らない。悪は谷として『引く』のが対比の作法。語が『安い/滑る』でも谷扱い。

### 質感の格上げ（メタファー昇格）
ありふれた属性(色/素材)をまず平易に置いてから比喩で高級へ昇格させる。同じ事実を詩的言い換えで山に変える。見分け=『○○な△△』(平叙)→『〜を〜する△△』(比喩)の二段・前段は地味/後段で跳ねる。
推奨: telop=前段:立(平叙・最小)/昇格:締強＋温度:white(比喩句を隔離) / cut=前段:提示→昇格:寄りディテール / se=前段:無音/昇格:衝撃:強(質感の頂点に最強級) / pace=前段:標準/昇格:溜め / framing=前段:中→昇格:寄り(質感が見える最寄り)

### 逆説の自信（欠点を美点に反転）
一見の欠点を先に晒し(谷)、『だから〜』で美点・哲学へ反転(山)する。欠点提示の引きが反転の効きを生む。見分け=『○○がない／○○なのに』(欠点)→『だから〜』(反転の言い切り)・覚悟/信念ワード。
推奨: telop=欠点:抜(淡々と地の文)/反転:締強＋温度:white(信念を言い切る) / cut=欠点:提示(短く)→反転:余韻ホールド / se=欠点:無音/反転:衝撃:中(信念を打つ) / pace=欠点:詰め/反転:溜め / framing=欠点:引き/反転:寄り(自信に近づく)
- ★注意：欠点側を悲観で殴らない。淡々と引くほど反転が効く。

### 中毒の確信（戻れない）
機能の証明から感情のフックへ転換し、『もう戻れない』と離脱不能・所有欲を当事者目線で断定する。判定を視聴者の未来体験として先取りさせる。見分け=『履いたら/使ったらわかる』＋鉤括弧の生声断定・他との比較不能の言い切り。
推奨: telop=締強＋温度:white(鉤括弧句を隔離) / cut=余韻ホールド(着用/使用の継続を残す) / se=衝撃:中(生声の節目) / pace=溜め / framing=寄り〜中寄り(当事者の視点)
- ★注意：ポジティブ・どんでん(数値の衝撃)と並ぶと両方締強になりがち。どんでん＝数値の驚き、中毒＝感情の確信、で顔を分ける。
