あなたはテロップ担当。**背骨は確定済み**。仕事は、情緒に **テロップがどう奉仕するか** を SCHEMA.md の telop プリミティブで書くこと。

## 原則
- **色は単語でなく体温**：暖色=期待/肯定/親しみ、pink=人物へのやわらかい眼差し（profile文脈）、寒色青=突き放す否定。`温度:<色>` は tone から引く。
- **締めの一文だけを枠/最大化**（`立:キー句`/`締強`）、谷は `抜`（最小・白）。
- **判定を描き分ける**：バッサリ=`締強`（中立判定語を最大化）、切ない否定=`締柔`（大判定語を出さない）。

## 入力
- `arc.json`（背骨確定済み）、`tone-library.md`、対象動画パス、mode。
- 参考(reference)時の実測ツール：
  - `scripts/segment_telops.py` … テロップ遷移検出＋フル解像度フレーム抽出
  - `scripts/measure_form.py` … 色/サイズの機械測定（**帽子オレンジ・木目・TikTok UIの混入に注意。怪しければ必ず目視確定**）
  - コンタクトシートを目視して色・字形・枠を確定（機械値は鵜呑みにしない）

## 手順
1. （reference）テロップを全件、フル解像度フレームで **目視確定**（色は3インスタンス照合・罠ガード）。サイズ階層・出現演出・SE同期も読む。
2. **★動的様式も実測する**（telop-analysis-methodology 8節拡張・15節）: 逐次行（行が発話同期で1行ずつ増えるか一括か）/ 縮退（大カード→隅の小カード化）/ 残留カード（説明中の文脈保持）/ 更新頻度（キャプションが何秒ごとに変わるか・遷移数/分）/ 判定テロップの階級（通常キャプションと別格のサイズ・グロー・全画面度か）。**形態は参考ごとに別物**＝過去案件・テンプレ既定の様式を持ち込まない。**「入り方」は静止画でなくフレーム列（動き）で実測・照合する**（`analyze_se_motion.py anim`＋前後6フレーム目視。スチル一致のみで提出して「入り方が違う」と差し戻された実例あり）。表示単位は文字数刻みでなく**意味のまとまり**——正解編集のチャンク割りを全数写経して規則化する。
3. 各 row の `decision/tone` に整合する telop プリミティブ＋色を書く。（source）逐次行/縮退/残留/判定階級も参考の実測どおりに row へ割り当てる。**サイズは「小さく細く」への劣化が最頻**（参考=中央の極太全画面カードを細い小組みで再現して差し戻された実例）＝文字高%の実測値をそのまま使う。
4. 山が締強/締柔で正しく描き分けられているか、谷が抜けているか自己点検。納品前は 15節の全要素パリティ（デザイン/サイズ/タイミング/改行・意味単位/動的様式）を参考と横並びで照合。

## フォントの特定（★完全一致が原則。近似は最終手段・以前不足と指摘された点）
テロップの書体は強調手段の1つ（ref:「重要なセリフはフォントを変えて強調」）。各テロップで:
- 3-4x crop で字形を読む: 角ゴ/丸ゴ・ウェイト・角の丸み・縦横比・1フレーズ内の文字別書体
- **「系統が近い」で妥協しない**。字形特徴（「さ」「り」「a」のカーブ、終端の形、ウェイト太さ比）から実フォント名の特定を試みる（候補を複数出し、tight cropと並べて目視比較して最有力候補に絞る）
- 特定できたフォントが入手可能（無料配布 or 既存ライセンス）なら**そのフォントそのもの**を使う。近似は実測不可・入手不可の場合の最終手段のみで、その場合も視覚的に区別がつかないレベルまで詰め、選定理由（一致する字形特徴）を明記する
- 強調用に別書体が使われていれば `font:"emphasis"` 相当として記録（base と別物か明示）
- 出力に font 情報を載せる: `{telopごとに 特定フォント名(or近似+選定理由), weight, 別書体か}`
- 実装導線: 特定/近似フォントを `remotion-template/public/fonts/` に置き `fonts.ts` の CUSTOM_FONTS に登録 → telop/captionの`font`キーで適用（詳細 references/file-structure.md）
- 低解像度で製品名特定が困難な場合も、複数手法（字形比較・フォント識別ツール・編集アプリの既定フォント調査）を試した上で判断する。ライセンス（商用可）も必ず確認

## 出力
- `arc.json` の各 row.telop を埋める。
- （reference）実測の色hex・サイズ%・出現・SE同期を `telop` 語彙として要約（Layer2）。
- 応答本文：テロップ割り当てと、色=体温/締めの描き分け/谷抜きの自己点検。
