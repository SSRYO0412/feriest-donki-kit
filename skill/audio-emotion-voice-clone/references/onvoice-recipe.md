# VOナレーション版 動画再構築レシピ（汎用版）

> 正本: `core/vo/references/onvoice-recipe.md`（sync_core.sh で配布）。
> テロップのみの動画に VO（ナレーション）を乗せ、カット/テロップをVOに同期して再構築する手順の**枠組み**。
> ★本書中の数値（オフセット秒・LUFS目標・増速率・許容帯）はすべて**参考動画・承認済み動画からの実測値の例**であり、案件ごとに再測定して決める（PRINCIPLES §1。再利用してよいのは手順と語彙の枠だけ）。
> VO生成そのものは `audio-emotion-voice-clone` スキル（クローン・K候補生成・閉ループ選別）を使う。

## 入力
- 元カットリスト（cut id / rel / tin / dur / テロップ文言）
- VO最終wav + 行タイムスタンプ（QA JSON: 各ナレ行の開始/終了秒）
- 素材実尺の一覧（sources.json等。尺不足チェックに使う）
- 検証済みクリップ台帳（窓依存素材の禁止帯チェックに使う）

## 1. VO生成
- 台本行 = カットリストのテロップ列（+CTA行等）。**表記変換（読み仮名化・数字の読み下し）のみ可、文言変更は厳禁**。
- クローン音声はK候補生成→行尺フィット（無音トリム→atempo。比が大きすぎる行は最短候補へ差替）→全体テンポ調整+行間の息継ぎ挿入→**逆QA全行確認**（生成物を元と同じ計測で突き合わせ）。
- 声質モデルは案件指定に固定（勝手に別TTS・別声にしない）。抑揚は既存合格音声に寄せる。

## 2. 行別ラウドネス正規化（必須・省略すると行が沈む実害あり）
- fit済み各行のLUFSを実測し、**中央値±数LUへソフトクランプ**（クランプ幅は承認済み動画のスプレッド実測に整合させる。実測例: ±4LU）。
- 怠ると特定行だけ沈む（LRA過大として独立検査で検出された実績）。

## 3. カット/テロップ再タイミング
- 新カット開始時刻 = そのカットの最初の担当ナレ行の開始時刻 + **固定オフセット**（参考動画から実測。実測例: +0.24s、参考実測帯+0.20〜0.38）。先頭カットは0秒開始。
- 動画総尺 = VO尺 + 小さな余白（最後のカットで吸収）。
- カット尺 = 次カット開始との差。tinは元カットリストの値を維持。**tin+新durが素材実尺を超える場合のみ**tinを前倒し（大きい前倒しは要窓検証）、それでも足りなければ報告に書く（勝手に素材を差し替えない）。
- **窓依存素材の禁止帯チェック**: durが伸びるため、台帳に窓限定記載のある素材・「X-Y秒使用不可」系素材は、新窓が禁止帯に入らないか必ず数値チェック。収まらなければ窓検証フレームを増やして目視、それでも無理なら報告。
- テロップは**1ナレ行=1テロップ**。1カットが複数行を担当する場合、同一rel/連続tinのサブセグメントに分割して各行を個別表示（切替も行頭+同オフセット）。参考動画が2行同時に組んでいたペアのみ例外。**同一素材の連続サブセグメント分割で「見た目のカット」は増やさない**。

## 4. 素材尺不足の許容解（素材差し替えが禁止されている場合）
1. 軽微スロー（≤15%, setpts）
2. パリンドローム延長（順再生+終端逆再生。**静止ポーズのみ**、方向性のあるモーションには使用不可）
3. 末尾hold（≤0.2s、低モーションのみ）

いずれもフレーム目視必須。

## 5. ミックス確定チェーン（構造は共通・数値は案件実測）
```
VOプリゲイン(基準LUFSへ) → ゲイン → limiter → BGM減衰 → amix → 仕上げゲイン → limiter
```
- 着地目標（統合ラウドネスI・Peak・LRA・声-BGM比）は**参考動画のebur128実測**から決め、明示許容帯付きで管理する（実測例: I=-16.9±0.4 / Peak<-1.0 / LRA≤5.2 / 声-BGM比11.3LU）。

## 6. QAゲート（全項目PASSまで反復）
- 逆QA全行（VO行の欠け・重複・順序）
- シーン境界±0.15s・ラグ帯の確認
- 輝度ガード（**納品ファイルの実際に使用するカット窓の中央フレーム**で測る。ソース素材の別時刻で測るのは無効）
- 窓依存素材の窓目視
- ラウドネス実測（報告値でなく納品ファイルを親が再実測。報告-16.9/実測-18.1の齟齬事例あり）
- 外部AI独立検査は**明示許容帯付きで**依頼（帯なしだと判定がブレる）

## 既知の罠
- glob `<id>_work*` は再実行分（work2等）も拾って二重連結する。連結リストは明示列挙。
- 短尺クリップのdur厳守（ffmpegエラー）。
- 「使用不可秒数」注記素材はdur延長で禁止帯またぎに注意。
- 旧版から引き継いだカットに禁止素材が残存していないか、再構築時に全カットを台帳と突き合わせる。
