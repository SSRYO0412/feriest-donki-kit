実装の詳細・罠は `skills/premiere-bridge-ops/`（SKILL.md / references/MOGRT.md）を見る。

|---|---|---|---|---|---|---|---|

| **`telop_v30_fontedit.mogrt`** | **本文＋80** | **60秒** | **4色** | **○** | ○ | ○ | ○ |

★**迷ったら `telop_v29`。** 全部入りで、しかも**60秒まで伸ばせる**。4色グラデが要るときだけ v30。

### ★★★ 素材長（テロップの最大尺）

**MOGRT の尺は「テンプレのコンプ長」で決まる。** `clip.end` でそれを超えて伸ばしても、
**その先は描画されない**。しかも**読み戻しでは分からない**（クリップは伸びて見えるだけ）。
気づけるのは**書き出した画素を見たとき**だけ。

- **5秒版（v22〜v28）** … 150F を超えた分は出ない。長い区間は**複数枚を隙間なく敷き詰める**
  （例: 337F = 0-150 / 150-300 / 300-337）
- **60秒版（v29/v30）** … 1800F まで1枚で伸ばせる

**使い方は「長いテンプレを入れて、必要な尺にトリムする」**。挿入時の既定クリップ長は
コンプ長（60秒）になるので、**必ず `clip.end` で詰める**。

```javascript
var clip = seq.importMGT(MG, String(Math.round(sec * TPS)), vTrack, aTrack);
var e = new Time(); e.seconds = 終了秒; clip.end = e;    // ★必ず詰める
```

★**書き出しで60秒ぶんレンダーされることはない。** レンダーされるのはタイムラインに
乗っている尺だけで、コンプ長は「どこまで伸ばせるかの上限」でしかない。

★**もっと長い尺が要るなら**、雛形（`templates/ae_build_telop_mogrt_v11.jsx`）の
`DUR` を変えて作り直す（After Effects が要る）。**既にある `.mogrt` の尺は後から変えられない。**

## 共通の決まりごと（これを外すと必ずハマる）

1. **数値は 0〜100 に収まる。** EGPのスライダーは Premiere 側で 0〜100 に丸められる。
   色は **0〜100（％）**で指定する（0〜255 ではない）。例: `R=100, G=84, B=0` で金。
2. **ドロップダウンは「AEの値 − 1」。** Premiere は 0 始まり。
   例: 出現の型 AE `1=なし` → Premiere では `0`。
3. **本文を変えたら `fontTextRunLength` を文字数に合わせる。**
   揃えないと `setValue` は通るのに **UI で開いた瞬間に Premiere が落ちる**。
4. **ExtendScript に `JSON.parse` は無い**（`eval(` はブリッジが弾く）。本文は**正規表現**で書き換える。
5. **MOGRT の素材長は 150F（5秒）。** `clip.end` で超えて伸ばすと **150F 以降は描画されない**
   （クリップは伸びて見えるので読み戻しでは気づけない）。長い区間は複数枚を敷き詰める。

```javascript
// 本文の差し替え（定型）
var v = tp.getValue();
var p = v.replace(/("textEditValue":")(?:[^"\\]|\\.)*(")/, '$1' + TXT + '$2');
p = p.replace(/("fontTextRunLength":\[)[^\]]*(\])/, '$1' + TXT.length + '$2');
tp.setValue(p, true);
```

## パラメータ一覧

### 文字まわり

| 項目 | 範囲 | 意味 |
|---|---|---|
| 本文 | 文字列 | ソーステキスト。**書体・サイズもここ**（`fontEditValue` / `fontSizeEditValue`） |
| 縦位置 | 0〜100 | 画面の縦位置（％）。既定75 |
| **文字間隔** | 0〜100 | **50が標準**。50からの差が効き量（1あたり約7px @120px） |
| 文字色R/G/B | 0〜100 | 単色のときの文字色。グラデONのときは「グラデの効き0」で戻る先の色 |
| 縁の太さ | 0〜100 | 0でフチ無し |
| 縁色R/G/B | 0〜100 | フチの色 |

★**書体は PostScript 名で指定する**（`fontEditValue`）。
**未インストールのフォントは AE も Premiere も警告なしに代替する**ので、
差し替えたら**書き出した画素で字形を確かめる**こと。

### グラデーション（v25/v26/v27/v28）

| 項目 | 範囲 | 意味 |
|---|---|---|
| グラデ表示 | 0 / 100 | 0=OFF（単色＋強調色）/ 100=ON |
| 開始色R/G/B・終了色R/G/B | 0〜100 | 2色グラデの色（v25/v27） |
| 色1〜4 R/G/B | 0〜100 | 4色グラデの色（v26/v28） |
| 開始X/Y・終了X/Y | 0〜100 | **50が中立**（文字ブロックにぴったり）。50からの差×4px ずれる |
| 点1〜4 X/Y | 0〜100 | 4色版。**文字ブロック内の相対位置(%)**。0,0=左上 |
| グラデの形 | 0/1 | **0=線形 / 1=放射状**（AEの値−1） |
| グラデの効き | 0〜100 | **100=グラデそのもの / 0=文字色の単色**。中間で連続的に薄まる |
| グラデのざらつき | 0〜100 | 帯のバンディング（縞）を散らす |
| にじみ | 0〜100 | 4色版の混ざり具合。下げると4色が分離する |

★**「形」は線形と放射状の2つだけ**（AEの仕様）。ただし開始点/終了点が自由なので、
**斜めグラデ・帯の広さ・中心をずらした放射状**は全部作れる。
★**5色以上の多段グラデは原理的に不可**（AE側が露出を許さない）。

### グロー（v22 / **v27** / **v28**）

| 項目 | 範囲 | 意味 |
|---|---|---|
| グローの強さ | 0〜100 | 0で無効 |
| グローの種類 | 0〜3 | **0=なし / 1=ソフト / 2=ハード / 3=ワイド**（AEの値−1） |

★v27/v28 では**表示されている色から光る**（グラデONなら光彩もグラデ色に追従する）。
★**背景が明るいとグローは見えない。** 効いていないと思ったら**まず背景色を疑う**こと。

### 影・下地（v25以降）

| 項目 | 範囲 | 意味 |
|---|---|---|
| 影の距離 / 影の柔らかさ | 0〜100 | px |
| 影の濃さ | 0〜100 | **0で影が消える**（v22 と同じ見た目にしたいときは 0） |
| 下地の表示 | 0 / 100 | 文字の背後に半透明の黒板を敷く |
| 下地の濃さ / 横余白 / 縦余白 | 0〜100 | 濃さは％、余白は px |

★**v22 には影が無い。v25以降は既定で影が付く（濃さ45）。**
v22 と同じ見た目にしたいなら **`影の濃さ = 0` を明示**する。

### 出現アニメ

| 項目 | 範囲 | 意味 |
|---|---|---|
| 出現の型 | 0〜4 | **0=なし / 1=フェード / 2=ポップ / 3=下からスライド / 4=タイプライター**（AEの値−1） |
| 出現の尺 | 0〜100 | **×0.01秒**（50 → 0.5秒） |

### 強調スロット（1〜3）

| 項目 | 範囲 | 意味 |
|---|---|---|
| 強調の出方 | 0〜3 | 0=なし（最初から）/ 1=後から跳ねる / 2=後から色が乗る / 3=跳ねて色も乗る |
| 強調n開始 / 強調n終わり | 文字数 | **何文字目から何文字目か**（1始まり）。0,0 で無効 |
| 強調nの大きさ | 0〜100 | 拡大量（％の追加分） |
| 強調nの遅れ | 0〜100 | ×0.01秒 |
| 強調n色R/G/B / 強調n縁色R/G/B | 0〜100 | 強調部分の色 |
| 強調nの縁の太さ | 0〜100 | **本文の縁への追加分**（0で本文と同じ） |
| 強調nの縦オフセット | 0〜100 | 上に跳ね上がる量(px) |

★**グラデONのとき強調の「色」は見えない**（グラデが全文字を覆うため。仕様として排他）。
**大きさ・跳ね・縦オフセットはグラデONでも効く。**
★**改行も1文字として数える。**

## 置き方（定型）

```javascript
var TPS = 254016000000;
var clip = seq.importMGT(MG, String(Math.round(sec * TPS)), videoTrack, audioTrack);  // ★ticksは文字列
var mgt  = clip.getMGTComponent();
if (!mgt) { /* ★AE製でない＝使えない。中断する */ }
var props = mgt.properties;
function setByName(nm, v) {
    for (var q = 0; q < props.numItems; q++)
        if (props[q].displayName === nm) { props[q].setValue(v, true); return true; }
    return false;   // ★名前が違えば黙って何も起きない。戻り値を必ず見る
}
```

★**設定できたかは戻り値で確かめる。** 名前を間違えても例外は出ない。
★**最終判断は書き出した実ファイルの画素で行う**（読み戻しだけで「効いた」と言わない）。

## 作り直したいとき

雛形は `skill/donki-feriest/templates/` にある（After Effects が要る）。

| .mogrt | 雛形 |
|---|---|
| `telop_v27_fontedit.mogrt` | `ae_build_telop_mogrt_v9.jsx` |
| `telop_v28_fontedit.mogrt` | `ae_build_telop_mogrt_v10.jsx` |
| **`telop_v29_fontedit.mogrt`** | **`ae_build_telop_mogrt_v11.jsx`**（v9 の `DUR` を60秒にしたもの） |
| **`telop_v30_fontedit.mogrt`** | **`ae_build_telop_mogrt_v12.jsx`**（v10 の60秒版） |

```bash
AE_OUTDIR=~/Desktop/mogrt bash skills/premiere-bridge-ops/scripts/ae.sh \
  skill/donki-feriest/templates/ae_build_telop_mogrt_v9.jsx 240
python3 skills/premiere-bridge-ops/scripts/mogrt_enable_font_edit.py 出力.mogrt 出力_fontedit.mogrt
python3 skills/premiere-bridge-ops/scripts/mogrt_scrub.py --in-place 出力_fontedit.mogrt
```

★**②のフォント編集解禁を飛ばすと書体もサイズも変えられない。**
★**③を飛ばすと作者マシンの絶対パスが `.mogrt` に残る。**
