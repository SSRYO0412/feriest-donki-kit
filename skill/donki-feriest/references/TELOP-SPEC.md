## 3. ★★下段の色の決め方（ここで一度失敗した）

「素材の色」ではあるが、正確には
**「食材を思わせる色 かつ 背景から浮く彩度」**。

**背景の支配色をそのまま採ると文字が埋もれる。**

判定は**背景平均色との色差 ΔRGB**（ユークリッド距離）で行い、
**参考の実測帯 93〜142** を下限の目安にする。

| | テロップ色 | 背景 | ΔRGB |
|---|---|---|---|
| 参考 とろろ明太 | `#EAB1A3` | `#989083` | 93.3 |
| 参考 から揚げタルタル | `#EFE919` | `#C1B795` | 141.8 |
| **踏んだ失敗**（海老の地色をそのまま使った） | `#D4B27D` | `#C6A26B` | **27.2 → 読めない** |
| 是正後（コーラル） | `#F2704F` | `#C6A26B` | 71.8 |

**測り方**: テロップ帯の左右端（文字の無い所）と帯の下から背景の平均色を取り、
テロップの塗り色との距離を出す。

## 4. ★参考は8文字でも1行のまま

「から揚げタルタル」（8文字）でも改行せず、**フォントを115pxに縮めて幅いっぱい**に置いている。

文字数が多いときに1行のまま縮めると**上段（68.948）より小さくなって強調が消える**。
そういうときは**行を割ると参考のサイズ帯（131〜141）に戻せる**。

## 6. ★`縦位置` パラメータの意味

**中心ではなく「テキストの下端」**。

`縦位置(%) × 1920 = 文字の下端 y`

検算（2点で確認）:
- 81.71% × 1920 = 1568.8 → 実測の下端 1571px（差2px）
- 83.76% × 1920 = 1608.2 → 実測の下端 1608px（差0px）

## 7. MOGRT v22 の扱い

★**v22 を使う。v20 は色がカラーピッカー方式でスクリプトから触れない。**

v22 は `文字色R/G/B` `縁色R/G/B` が **0〜100 の数値**（0〜255ではない）。

本文を書き換えるときは **`fontTextRunLength` を文字数に合わせる**
（揃えないと UI で開いた瞬間に Premiere が落ちる）。

```javascript
p.setValue(v.replace(/"textEditValue":"[^"]*"/, '"textEditValue":"'+txt+'"')
            .replace(/"fontTextRunLength":\[[^\]]*\]/, '"fontTextRunLength":['+txt.length+']')
            .replace(/"fontEditValue":\["[^"]*"\]/, '"fontEditValue":["'+font+'"]')
            .replace(/"fontSizeEditValue":\[[^\]]*\]/, '"fontSizeEditValue":['+size+']'), true);
```

### ★★強調（部分強調）の発火条件

**`出現の型 = なし` だと `強調の出方` を何にしても1pxも動かない。**
`強調の遅れ` は**出現アニメが終わってからの秒数**なので、出現が無いと起点が立たない。

| `強調の出方` | 効き方 |
|---|---|
| `0`（なし） | **静的に効く**。指定した範囲が最初から大きく・別の色になる |
| `1`以上 | **アニメのみ**。静的には効かず、出現アニメの後に一度だけ動く |

**振幅**: `強調1の大きさ` 25 では30fpsで**1フレームしか動かない**。**40〜60**で10〜27フレーム動く。

**文字の添字は1始まり**（8文字なら 1〜8）。

★**強調で本文の幅が右へ伸びる**ので、隣に置いた画像（絵文字など）と衝突する。
大きさを変えたら**本文の最大右端を全フレームで測ってから**画像を置き直す。

## 9. 絵文字

**ファイル名は Unicode コードポイント**（`1f447.png` = 👇 / `1f364.png` = 🍤）。
**72×72 の Twemoji**（参考が使っているのと同じセット）。同梱: `../assets/`

- **描画高さ ＝ フォントサイズ**（スケール = フォントサイズ ÷ 72 × 100）
- **画像の中心を本文の中心に合わせる**
- 本文の末尾に**全角スペースを1つ**入れてその上に重ねる
- 置いたら**書き出して拡大目視で位置を詰める**（計算値のままにしない）

★**色マスクは背景に汚染される**（食材のオレンジ等）。裁定は拡大目視。
