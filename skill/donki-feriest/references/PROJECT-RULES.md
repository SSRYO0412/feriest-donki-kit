## 3. 環境の罠（すべて実際に踏んだ）

- **ExFAT の NFD 問題** — 日本語ファイル名の正規化差でパスが一致しない。
  `unicodedata.normalize` を通すか glob で拾う
- **zip展開は `ditto -x -k`** — `unzip` だと日本語名が文字化けする
- **`._*` の AppleDouble が264個混入** — 解析時は `-not -name "._*"` で除外
- **Driveの同名フォルダ** — ルート直下に同名が2つずつ9組ある。
  `rclone lsjson -R` の一括再帰は**取りこぼす**（268本と出るが実際は315本）。
  **`--drive-root-folder-id` をフォルダIDごとに与えて再帰する**
- **ExFAT マウントが落ちる** — 並列を上げすぎたとき。par15 を超えない
